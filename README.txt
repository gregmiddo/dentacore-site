DentaCore website
=================

To view it: unzip this folder anywhere, then double-click index.html.
It opens in your web browser and works without an internet connection.

The site has 18 pages: the overview (index.html), "Every feature, A to Z"
(features.html), 15 feature pages and "Why DentaCore" (why.html).
On a computer each feature fits on one screen: use the list on the left,
the Next and Previous buttons, or the arrow keys.
The Features menu at the top of every page reaches all of them.

Keep all the files and folders together (the .html files, site.css,
site.js, the img folder and the fonts folder).

To put it online, upload the whole folder as it is to any web host
(GitHub Pages, Netlify, Cloudflare Pages or your own).

Demo requests go to greg.middleton@eyceline.com (the email on the home page).

IMAGE-SOURCES.md lists where each X-ray image came from.
